# LedgerLens Pro - Financial Intelligence Platform

## Quick Start

```bash
# Install all dependencies
npm install

# Start development servers
npm run dev

# Validate evidence
npm run validate
Services
- Frontend: http://localhost:3000
- Backend API: http://localhost:4000
- ML Engine: http://localhost:8001
Features
- Real-time PayPal balance tracking
- 30-day Monte Carlo cash flow forecast
- Scenario simulator
- Anomaly detection
- PayPal API integration
Evidence Validation
npm run validate
Generates manifest.json with SHA-256 hashes of all evidence files.
