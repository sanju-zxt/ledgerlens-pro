## Release state

The code can be tested and built locally, but it is not ready to claim multi-merchant production use or real-world model performance. A local deterministic synthetic benchmark is available separately and is labeled synthetic; it does not close the first or second gate. Do not claim deployment of this branch until the production URLs are checked after deployment. Do not claim the demo-video gate until the public video URL is verified.
